# FE Radio

Маленькое фиолетовое радио для Roblox (Murder Mystery 2 и любые другие игры).

- В MM2 с Radio-пассом играет через официальное радио — слышат все в лобби
- В других играх — локальный звук без бумбокса, слышишь только ты
- Коды треков, история «название — код» (сохраняется в файл)
- Избранное на звёздочке, пауза/стоп, перемотка, громкость до x10
- Каталог lylib.fun + свой сборник с GitHub (поиск, страницы, следующий/предыдущий трек)
- Мут чужих радио

## Запуск

1. Вставь `FE-Radio.luau` в свой executor и запусти в игре
2. Введи код трека и жми «Играть»
3. Сборник подтягивается сам: https://boja1586.github.io/glassradio-tracks/
